# AWS IAM Policies for Seqera Platform

This repository provided AWS Identity and Access Management (IAM) policies for using the Seqera
Platform with AWS Batch.

The repo has now been deprecated. Please refer to the official Seqera documentation for the most up-to-date
information on configuring Seqera Compute Environments with AWS Batch:
[cloud](https://docs.seqera.io/platform-cloud/compute-envs/aws-batch) and
[enterprise](https://docs.seqera.io/platform-enterprise/compute-envs/aws-batch).
